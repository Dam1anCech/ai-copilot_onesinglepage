# Citace a použité zdroje

## Jak stránka vznikla

Webové portfolio designéra bylo vytvořeno jako samostatná jednostránková prezentace. Obsah a struktura jsou v `index.html`, vzhled a responzivní pravidla v `style.css`. Stránka používá sémantické HTML, vlastní CSS layouty a jednoduché CSS ilustrace vytvořené přímo pro tento projekt.

## Použité technologie a nástroje

- **HTML5** — struktura stránky, navigace, projekty a kontaktní informace.
- **CSS3** — barvy, typografie, rozvržení, responzivní zobrazení a ilustrace; bez JavaScriptu a CSS frameworku.
- **VS Code / Copilot** — tvorba a úprava souborů v projektu.
- **Integrovaný prohlížeč** — kontrola vykreslení stránky na desktopové i mobilní šířce.

## Externí zdroje

Písma se načítají ze služby Google Fonts. Pokud stránka nemá přístup k internetu, prohlížeč použije systémová náhradní písma uvedená v CSS.
